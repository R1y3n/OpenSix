# Contributing

Open an issue for a new file format, an archive compatibility problem, or an incorrect preview. Include the OpenSix commit or version, Windows version, executable SHA-256, archive format, entry hash or file type, and the shortest steps that reproduce the problem. For a filename report, include the candidate path and the hashes shown in entry details.

Use a synthetic sample or a small fixture you can redistribute. Keep game binaries, archives, extracted assets, keys, tokens, local paths, and crash dumps out of issues and pull requests.

Keep changes focused. For format changes, include the fixture or evidence used to test them and describe which variants you verified. Run the desktop app on Windows for changes to the picker, navigation, viewers, or extraction. See [Build OpenSix](docs/build.md).
